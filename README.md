### 💬 Message Bubble Generator
> Dependency-free browser tool that animates a chat conversation on a chroma-key background and exports it as WebM. Every bubble is drawn on a `<canvas>` at output resolution, so the recording is pixel-identical to the preview. Handles Thai wrapping and tone-mark clipping.
